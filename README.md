## EcoDomStroy — AI-консультант на базе RAG

> **Учебный проект** по курсу «Использование ИИ» — демонстрация архитектуры RAG (Retrieval-Augmented Generation) с красивым веб-интерфейсом, каскадным LLM-клиентом и формой захвата лидов.

---

### Что делает приложение

- Отвечает на вопросы о строительстве быстровозводимых домов (каркасные, модульные, SIP, дачные)
- Ищет релевантные фрагменты из базы знаний по **смысловому сходству** (не по ключевым словам)
- Показывает **топ-5 чанков** с оценками similarity перед ответом LLM
- Принимает заявки от клиентов (имя, e-mail, телефон) и сохраняет их в `leads.json`
- Поддерживает светлую / тёмную тему, историю диалога, рендеринг Markdown в ответах

---

### Архитектура: как работает RAG

```
Вопрос пользователя
       │
       ▼
┌─────────────────┐      ┌──────────────────────────────────┐
│  Эмбеддинг      │      │  База знаний (txt-файл)          │
│  запроса        │      │  → нарезка на ~549 чанков        │
│  (384-мерный    │      │  → эмбеддинг каждого чанка       │
│   вектор)       │      │  → матрица [549 × 384] в RAM     │
└────────┬────────┘      └──────────────┬───────────────────┘
         │                              │
         └──────── cosine similarity ───┘
                        │
                        ▼
              Топ-5 похожих чанков
                        │
                        ▼
         Формируем промпт: system + история + контекст + вопрос
                        │
                        ▼
              LLM (OpenAI → Qwen → OpenRouter)
                        │
                        ▼
                  Ответ клиенту
```

**Ключевая идея:** LLM отвечает ТОЛЬКО на основе найденных чанков — не выдумывает факты.

### Модель эмбеддингов

**`paraphrase-multilingual-MiniLM-L12-v2`** от Sentence Transformers:
- Размер: ~117 МБ
- Вектор: 384 измерения
- Язык: поддерживает русский (multilingual)
- Устройство: CPU (без GPU)
- Поиск: косинусное сходство через матричное умножение (векторы нормированы, поэтому `dot product = cosine`)

**Кэш эмбеддингов** (`embeddings_cache.npz`):
- Хранит матрицу `[N_chunks × 384]` в бинарном формате numpy
- Fingerprint = SHA1(содержимое KB + кол-во чанков + имя модели)
- При изменении базы знаний кэш автоматически пересчитывается
- Закоммичен в репозиторий → первый старт на Replit ~5 сек вместо ~45 сек

### Каскад LLM-провайдеров

```
1. OpenAI (gpt-4o-mini)          ← если есть OPENAI_API_KEY
       ↓ не ответил / ошибка
2. Qwen / DashScope (qwen-plus)  ← если есть QWEN_API_KEY
       ↓ не ответил / ошибка
3. OpenRouter free-модели (перебор):
   - deepseek/deepseek-chat-v3-0324:free
   - deepseek/deepseek-r1:free
   - qwen/qwen3-235b-a22b:free
   - qwen/qwen3-30b-a3b:free
   - meta-llama/llama-3.3-70b-instruct:free
   - google/gemini-2.0-flash-exp:free
```

- **Таймаут:** 25 секунд на каждый запрос
- **Пауза между моделями:** 0.8 секунды
- **Классификация ошибок:** `LLMConfigError` (4xx — не повторять) vs `LLMTransientError` (429/5xx/timeout — пробовать следующую)

### Локальный запуск (Docker)

#### 1. Клонировать репозиторий
```bash
git clone https://github.com/<your-user>/ecodomstroy-rag.git
cd ecodomstroy-rag
```

#### 2. Создать `.env` из шаблона
```bash
cp .env.example .env
```
Заполнить хотя бы один ключ:
```
OPENROUTER_API_KEY=sk-or-v1-...
```

#### 3. Запустить
```bash
docker-compose up --build
```

Приложение доступно на **http://localhost:8800**

#### 4. Проверить здоровье
```
GET http://localhost:8800/api/health
→ {"ok": true, "chunks": 549, "error": null}
```

#### Запуск без Docker
```bash
python -m venv .venv
.venv\Scripts\activate       # Windows
# source .venv/bin/activate  # macOS / Linux
pip install -r requirements.txt
cp .env.example .env          # затем заполнить ключи
python main.py
```

### Нарезка базы знаний на чанки

Алгоритм в `rag.py`:

1. **Читает** `.txt` файл (UTF-8 или CP1251)
2. **Делит по заголовкам** `#`, `##`, `###` → секции с путём `"H1 / H2 / H3"`
3. **Длинные секции** разбивает по абзацам с перекрытием (overlap = 150 символов), чтобы не терять контекст на границах
4. Каждый чанк получает формат: `[Заголовок пути]\n\nТекст`
5. Итого: **~549 чанков** из базы знаний ЭкоДомСтрой

Параметры нарезки:
- `CHUNK_TARGET_SIZE = 1000` символов — целевой размер
- `CHUNK_MAX_SIZE = 1400` символов — максимальный размер
- `CHUNK_OVERLAP = 150` символов — перекрытие между соседними чанками

### Почему без LangChain?

Проект написан без LangChain сознательно:

| Задача | В LangChain | В этом проекте |
|---|---|---|
| Разбивка текста | `TextSplitter` | Свой алгоритм под структуру KB |
| Эмбеддинги | `HuggingFaceEmbeddings` | `SentenceTransformer` напрямую |
| Векторный поиск | `VectorStore` | `numpy` — одна строка кода |
| Цепочка с LLM | `ConversationalRetrievalChain` | Свой `generate_answer()` |

**Цель:** понять, как RAG работает изнутри, а не скрыть логику за абстракциями. Также меньше зависимостей → быстрее старт на Replit.
